## Final prompt

Create a completely new widescreen 16:9 high-resolution cybersecurity NETWORK ALERT background for the Drastha website. This is fresh concept art, not a revision of any previous hardware illustration.
Visual concept: A striking sprawling digital NETWORK GRAPH floating in deep black space, with fine luminous connections between numerous small circular endpoint nodes. The topology itself IS the subject. Branching clusters, routed connections, a few crisp packet trails, several highlighted suspicious paths. At three meaningful junctions, display unmistakable glowing orange OUTLINED WARNING TRIANGLES containing exclamation marks, anchored to the affected network nodes. Around those junctions, restrained circular alert ripples and orange-lit adjacent connections make it immediately read as 'network threats detected'. Small transparent outlined packet rectangles travel along some connections. Darker grey connections represent ordinary traffic; orange paths and highlighted node clusters represent anomalies. Vary node sizes and connection density to create a sophisticated connected cyber network, not a uniform mesh.
Art direction: elegant premium cyber threat-intelligence visualization, two-dimensional network topology with layered depth and subtle perspective, meticulous hairline geometry, restrained cinematic glow, sparse atmospheric particles, sharp foreground nodes and softly receding background links. Visually dynamic but clean. No physical objects or scene.
Composition: dense visual network in the RIGHT 60 percent, large anchor alert around x=75%, y=45%, two smaller alert markers elsewhere on the right. Connections curve and branch diagonally through the image. Left 40 percent fades organically into almost pure black negative space for the existing white headline. Keep alert markers comfortably inside the frame. Background edges fade into black for seamless website use.
Exact website palette: near-black #030303, charcoal #121212 and #303030, luminous warm orange #ff7638 and peach-orange #ff985f, sparse muted grey node highlights. NO blue, cyan, purple, green. Keep orange rich and controlled rather than washed-out yellow.
Project relation: passive network observation and threat alerting, not active intervention. No blocking or attacking imagery.
ABSOLUTELY NO hardware boxes, chips, processors, server racks, routers, appliances, circuit boards, podiums, trays, isometric platforms, physical cables, buildings, product renders, dashboards, panels, globes, maps, padlocks, shields, hooded people, skulls or robots.
No words, titles, logos, numbers, watermark or fake code. Only the exclamation mark inside warning triangles is allowed. Deliver an actual finished raster background image, not a website mockup.
